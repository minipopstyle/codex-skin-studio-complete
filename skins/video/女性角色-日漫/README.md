# Codex 视频皮肤：女性角色-日漫

这是当前 60fps 版本的视频皮肤包，结构与“自由女神”皮肤包一致。

## 内容

- `theme/background.mp4`：1920×1080、60fps、无音频视频
- `theme/poster.jpg`：与视频第一帧同步的静态海报
- `theme/theme.json`：皮肤配置与人物构图参数
- `安装物料.command`：安装本包物料
- `启动皮肤.command`：安装物料并启动皮肤
- `停止皮肤.command`：停止皮肤注入

## 使用

直接双击 `启动皮肤.command` 即可切换到本皮肤；双击 `停止皮肤.command` 可停止当前皮肤。

本包依赖已安装的 `~/.codex/codex-dream-skin-studio` 引擎，不修改官方 ChatGPT/Codex `.app`，也不包含 API Key、中转或代理配置。
